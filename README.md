 Tic-Tac-Toe AI
The link https://supery613.github.io/Tic-Tac-Toe-Ai/
A complete, responsive browser Tic-Tac-Toe game with a neon arcade look. No build tools or dependencies are required.

## Play

Open `index.html` in a modern browser, or publish the repository with GitHub Pages. Choose **VS CPU** for Easy, Medium, or Unbeatable difficulty, or switch to **2 Player** for a local head-to-head game. In CPU mode, choose X or O. The scoreboard tracks wins and draws until you reset it.

## Files

- `index.html` — accessible game layout and controls
- `styles.css` — responsive neon arcade styling
- `game.js` — game rules, CPU strategies, and scoreboard

The Unbeatable CPU uses minimax. The game is entirely client-side; Google Fonts are optional and used for typography.
